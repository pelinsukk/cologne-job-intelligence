# Project rules

- Implement milestone by milestone. Current scope: M0 and M1 only.
- Collect only through individually documented, authorized, free sources.
- Fail closed for UNKNOWN, RESTRICTED, BLOCKED, disabled or stale assessments.
- Respect robots.txt, terms, licenses and rate limits. Never bypass access controls,
  CAPTCHAs, anti-bot systems, blocks or prohibited scraping. Do not change hosts or
  identities to evade restrictions. Stop after denied access.
- No unnecessary personal data, contact harvesting, fabricated data or evidence.
- No paid services, billing, paid inference, GitHub Actions or cloud deployment.
- Local-first Python and SQLite; GitHub is source version control only.
- Never commit credentials, local databases, collected datasets or logs.
- Never automatically contact employers, send outreach or submit applications.
- Test authorization, network failures, persistence and CLI behavior with mocked
  network calls. Live collection requires independently verified permission.
- Report exact test results and limitations; planned features are not operational.
